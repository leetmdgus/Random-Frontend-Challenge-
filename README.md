# 🎲 Random Frontend Challenge

매주 **하나의 백엔드 기술**을 정하고, 그 기술을 연습할 수 있는 **랜덤한 서비스의 프론트엔드**를 받아
**백엔드를 직접 설계하고 구현**하는 주간 챌린지입니다.

프론트엔드는 미리 완성되어 Mock 데이터로 동작합니다.
API, 엔티티, 데이터베이스는 정답 없이 화면 동작만 보고 스스로 설계합니다.

## 진행 방식

1. [`프롬프트.md`](프롬프트.md) 의 **이번 주 핵심 학습**에 연습할 기술을 적는다.
2. 프롬프트로 랜덤 서비스의 프론트엔드(React + TypeScript)를 생성한다.
3. 프로젝트 README 의 **기능 목록 · 화면별 동작**을 읽고 백엔드를 설계한다.
4. `frontend/src/api/` 의 빈 연결 지점(TODO)을 채워 Mock 을 실제 API 로 바꾼다.
5. `VITE_USE_MOCK=false` 로 모든 화면이 Mock 과 똑같이 동작하면 완료.

> 규칙: 1주일 안에 끝낼 수 있는 규모 · 핵심 기술과 무관한 기능은 넣지 않기

## 프로젝트 목록

| 주차 | 서비스 | 핵심 학습 | 한 줄 소개 | 상태 |
| --- | --- | --- | --- | --- |
| 1 | [📌 주웠다](1_주웠다_FastAPI/) | FastAPI 기초 — CRUD · Query/Path 파라미터 · Pydantic 검증 · 상태 코드 | 줍거나 잃어버린 물건 쪽지를 붙이는 동네 분실물 게시판 | 🚧 진행 중 |

## 폴더 구조

```
Random-Frontend-Challenge-/
├── 프롬프트.md                     # 매주 사용하는 프론트엔드 생성 프롬프트
├── {주차}_{서비스명}_{핵심기술}/
│   ├── README.md                   # 서비스 소개 · 기능 목록 · 화면별 동작 · 연결 지점
│   ├── frontend/                   # 제공된 React + TypeScript 프론트엔드
│   └── backend/                    # 직접 구현하는 백엔드
└── ...
```

## 프론트엔드 실행

각 프로젝트 폴더에서:

```bash
cd frontend
npm install
npm run dev
```

자세한 내용은 각 프로젝트의 README 를 참고하세요.
